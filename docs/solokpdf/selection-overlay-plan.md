# 本文選択の重ね塗りとテーマ色の集約

## 状態（2026-11-08 実装済み）

`8cd54d631` で実装した計画の記録。現在の仕様は [features.md](features.md#selection-colors) を参照する。
テーマの `TextSelectionColor`、`SearchMatchColor`、`CurrentSearchMatchColor` に集約し、本文の文字再描画専用経路と
旧 `FixedPageUI.SelectionColor` を削除した。Forward Search とリンク移動の強調色は別設定を維持する。
以下は当時の実装範囲と検証項目であり、今回の文書整理で検証を再実行した記録ではない。

## 目的

本文の文字選択を軽量な半透明の重ね塗りに戻し、ドラッグ中も選択範囲を即座に表示する。選択や検索の色はテーマに集約する。`FixedPageUI.SelectionColor` の後方互換性は維持しない。

## 表示と設定

- テーマの `SelectionBackgroundColor` と `SelectionTextColor` は、リストやメニューなど UI の選択色として維持する。
- テーマに本文選択、検索結果、現在の検索結果の重ね塗り色をそれぞれ設ける。各色は合成前の色と透明度を表す。未指定時の色と透明度は、明暗テーマとページ配色を含む実画面で確認して決める。
- 本文の文字色は変更しない。重ね塗り後の色は文書の色との合成結果であり、テーマに指定した色と完全に一致しない。
- 旧 `FixedPageUI.SelectionColor` は、本文選択と検索描画の双方から参照を外し、設定定義と生成物から削除する。移行処理は設けない。
- 検索結果の上に本文選択を重ねる。重複部分は色が混ざるため、現在の「選択色が優先される」という説明を更新する。Windows と ng の描画順も確認する。
- Forward Search やリンク移動の強調色は別経路のため、テーマ集約の対象と用途を調査し、既存の動作を確認してから設定と描画を整理する。

旧 `OverlayReaching` は目的色に到達するため不透明度を上げることがあり、そのまま使うと Purpy で文字が見えにくくなる。本文の重ね塗りでは指定された透明度を保つ。合成後に選択が見分けやすく、文字が読める色を選び、必要なら細い枠線を併用する。任意の画像や文字色でコントラストを保証することはできない。

## 実装範囲

1. テーマ設定と取得処理を追加し、設定生成物と説明を更新する。透明度の表現、未指定と完全透明の区別を確認する。
2. 本文の選択矩形・四角形を既存の半透明描画へ渡し、検索描画もテーマ色へ移す。
3. 本文選択専用の文字解析・分割・再描画、描画要求、キャッシュ、取消、再試行、失敗注入を撤去する。MuPDF/PDFium の通常描画と共通処理は残す。
4. UI のテーマ色、選択範囲の計算、コピー、既存の描画に必要な処理を維持する。コミット済みの変更と未コミット差分が混在するため、コミット単位で一括 revert せず、用途ごとに整理する。
5. 現在の本文再描画と枠線フォールバックの説明を、新しい表示仕様に更新する。

## 検証

- PDFium と MuPDF で、マウスのドラッグ中・反転・縮小・解除時に重ね塗りが即座に追従し、残像や枠線との点滅がないことを確認する。
- Purpy、Purpy Slate と明暗テーマで、ページ配色の off / smart を含め、選択範囲と文字の可読性を確認する。合成後の画素も検査する。
- 検索結果・現在の検索結果・注釈と選択の重なり、選択範囲外の画素、透明度とテーマ切り替えを確認する。
- キーボード選択、コピー、可視空白、合字、矩形選択、回転、端数倍率、Escape での復元を確認する。
- 再描画専用の retry テストを撤去し、既存の文字色・フォールバックを前提としたテストを重ね塗りの仕様に合わせる。UI の選択色は別途維持確認する。
- GUI テストは `docs/solokpdf/testing.md` に従う。Release ビルドは毎回作成せず、必要な場合にのみ行う。
